# Ansible-Managed Fedora 44+/Arch Dotfiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public GitHub dotfiles repository where a tiny Bash bootstrap installs Ansible and an Ansible playbook manages Fedora 44+/Arch workstation configuration.

**Architecture:** `bootstrap` is the only Bash program. It detects Fedora or Arch, installs `ansible`, and invokes a local Ansible playbook. Bash does not enforce Fedora versions; Ansible rejects Fedora releases below 44 before package tasks. The playbook uses one inventory, one group variable file, and two plays: privileged package installation followed by unprivileged user-file copying. Dotfiles live under `home/`; unmanaged local files remain untouched.

**Tech Stack:** Bash bootstrap, Ansible, YAML, Jinja2, Git, Fedora `dnf`, Arch `pacman`, Niri, Waybar, Matugen, btop, Neovim/LazyVim.

**Spec:** `docs/superpowers/specs/2026-09-23-dotfiles-design.md`

## Global Constraints

- Public GitHub repository; public HTTPS clone must work without login.
- Target Fedora 44+ and Arch only.
- Bash detects Fedora or Arch; Ansible enforces Fedora 44+ before package tasks.
- `bootstrap` is the only Bash implementation; it only installs Ansible and invokes `ansible-playbook`.
- No Bash package loops, copy loops, backup logic, or dotfile management.
- Use Ansible built-ins only; no custom roles or collections.
- Include Niri, Waybar, Matugen, btop, Neovim, Alacritty, Fuzzel, Cava, xpad autostart, and helper scripts.
- Exclude Emacs, Firefox installation, secrets, SSH keys, tokens, wallpaper images, and machine caches.
- Keep Niri monitor definitions in untracked `~/.config/niri/hardware.kdl`.
- Keep `~/.config/current_wallpaper` local and never manage it from Ansible.
- Preserve unmanaged files and back up changed managed files.
- Do not commit a personal `.gitconfig` identity.
- Do not create or push the GitHub repository without a final user-facing stop at the publication boundary.

## File Map

- `bootstrap`: minimal distribution detection, `ansible` install, and playbook invocation.
- `ansible/inventory.ini`: one local `workstation` host using the local connection plugin.
- `ansible/site.yml`: supported-distribution assertion, package play, and user dotfile play.
- `ansible/group_vars/all.yml`: Fedora 44+ and Arch package lists.
- `home/.bashrc` and `home/.bash_profile`: portable Bash configuration payload only.
- `home/.config/niri/`: shared Niri config, generated colors, and `hardware.example.kdl`.
- `home/.config/waybar/`: Waybar layout, styling, and generated colors.
- `home/.config/matugen/`: Matugen config and templates for selected applications.
- `home/.config/btop/`: btop settings and Matugen theme.
- `home/.config/nvim/`: LazyVim configuration, lockfile, Lua configuration, and theme fallback.
- `home/.config/alacritty/`, `home/.config/fuzzel/`, `home/.config/cava/`: selected application configuration.
- `home/.config/autostart/xpad.desktop`: xpad autostart entry.
- `home/.local/bin/autostart-wallpaper` and `home/.local/bin/set-theme`: executable helper scripts.

- [ ] **Step 3: Implement `bootstrap`**

Create executable `bootstrap`:

```bash
#!/usr/bin/env bash
set -Eeuo pipefail

ROOT="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
OS_RELEASE="${DOTFILES_OS_RELEASE:-/etc/os-release}"

[[ -r "$OS_RELEASE" ]] || { printf 'error: cannot read %s\n' "$OS_RELEASE" >&2; exit 1; }
# shellcheck disable=SC1090
source "$OS_RELEASE"

case "${ID:-}" in
    fedora) package_command=(dnf install -y ansible) ;;
    arch) package_command=(pacman -S --needed --noconfirm ansible) ;;
    *) printf 'error: unsupported distribution: %s\n' "${ID:-unknown}" >&2; exit 1 ;;
esac

if ((EUID == 0)); then
    "${package_command[@]}"
elif command -v sudo >/dev/null 2>&1; then
    sudo -v
    sudo -n "${package_command[@]}"
else
    printf '%s\n' 'error: sudo is required to install ansible' >&2
    exit 1
fi

if ((EUID != 0)); then
    sudo -v
fi

exec ansible-playbook \
    --ask-become-pass \
    -i "$ROOT/ansible/inventory.ini" \
    "$ROOT/ansible/site.yml" \
    "$@"
```

No `cp`, `rsync`, package loop, backup logic, or dotfile logic belongs in this file.

- [ ] **Step 5: Implement the two-play Ansible playbook**

Create `ansible/site.yml`:

```yaml
---
- name: Install workstation packages
  hosts: workstation
  connection: local
  become: true
  gather_facts: true
  tasks:
    - name: Require Fedora 44+ or Arch
      ansible.builtin.assert:
        that:
          - ansible_facts['distribution'] == 'Archlinux' or ansible_facts['distribution'] == 'Fedora'
          - ansible_facts['distribution'] == 'Archlinux' or ansible_facts['distribution_version'] | int >= 44
        fail_msg: >-
          This playbook supports Fedora 44+ and Arch only; detected
          {{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }}.

    - name: Install dotfile dependencies
      ansible.builtin.package:
        name: "{{ dotfiles_packages }}"
        state: present

- name: Install user dotfiles
  hosts: workstation
  connection: local
  become: false
  gather_facts: true
  vars:
    dotfiles_home: "{{ ansible_facts['user_dir'] }}"
  tasks:
    - name: Create dotfile directories
      ansible.builtin.file:
        path: "{{ dotfiles_home }}/.config"
        state: directory
        mode: "0755"

    - name: Copy managed home files
      ansible.builtin.copy:
        src: "{{ playbook_dir }}/../home/"
        dest: "{{ dotfiles_home }}/"
        backup: yes
        mode: preserve

    - name: Check for local Niri hardware file
      ansible.builtin.stat:
        path: "{{ dotfiles_home }}/.config/niri/hardware.kdl"
      register: local_hardware

    - name: Seed missing Niri hardware file
      ansible.builtin.copy:
        src: "{{ playbook_dir }}/../home/.config/niri/hardware.example.kdl"
        dest: "{{ dotfiles_home }}/.config/niri/hardware.kdl"
        force: no
        mode: "0644"
      when: not local_hardware.stat.exists

    - name: Show local next steps
      ansible.builtin.debug:
        msg:
          - "Set Git identity locally with git config --global."
          - "Edit {{ dotfiles_home }}/.config/niri/hardware.kdl for this machine."
          - "Choose a wallpaper with set-theme; wallpaper state stays local."
```

The second play must not manage `current_wallpaper`, delete unmanaged files, or copy a personal `.gitconfig`.
