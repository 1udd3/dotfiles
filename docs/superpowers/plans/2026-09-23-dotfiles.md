# Portable Dotfiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public GitHub dotfiles repository with a Bash installer for Fedora and Arch machines.

**Architecture:** Store selected user configuration under `home/` and helper scripts under `bin/`. The installer detects the distribution, installs mapped packages, copies tracked files into `$HOME`, backs up conflicts, and preserves machine-local Niri and wallpaper files.

**Tech Stack:** Bash, Git, Fedora `dnf`, Arch `pacman`, Niri, Waybar, Matugen, btop, Neovim/LazyVim.

**Spec:** `docs/superpowers/specs/2026-09-23-dotfiles-design.md`

## Global Constraints

- Public GitHub repository; public HTTPS clone must work without login.
- Target Fedora and Arch only.
- Bash installer; no Chezmoi, Stow, or additional dotfile manager.
- Include Niri, Waybar, Matugen, btop, Neovim, Alacritty, Fuzzel, Cava, xpad autostart, and helper scripts.
- Exclude Emacs, Firefox installation, secrets, SSH keys, tokens, wallpaper images, and machine caches.
- Keep Niri monitor definitions in untracked `~/.config/niri/hardware.kdl`.
- Keep `~/.config/current_wallpaper` local and never overwrite it.
- Never overwrite an existing file without a timestamped backup.
- Re-run `install` after `git pull` to update managed files.
- Do not commit a personal `.gitconfig` identity.

## File Map

- `home/.bashrc` and `home/.bash_profile`: portable Bash startup files.
- `home/.config/niri/`: shared Niri configuration, generated colors, and `hardware.example.kdl`.
- `home/.config/waybar/`: Waybar layout, styling, and generated colors.
- `home/.config/matugen/`: Matugen configuration and templates for selected applications.
- `home/.config/btop/`: btop settings and Matugen theme.
- `home/.config/nvim/`: LazyVim configuration, lockfile, Lua configuration, and static theme fallback.
- `home/.config/alacritty/`, `home/.config/fuzzel/`, `home/.config/cava/`: selected application configuration.
- `home/.config/autostart/xpad.desktop`: xpad autostart entry.
- `bin/autostart-wallpaper` and `bin/set-theme`: local wallpaper/theme helper scripts.
- `install`: package installation, dry-run support, conflict backups, and file copying.
- `.gitignore`: local machine state and secret safeguards.
- `README.md`: public clone, update, installation, and local-override instructions.
- `tests/test_install.sh`: temporary-HOME installer regression test.
- `docs/superpowers/specs/2026-09-23-dotfiles-design.md`: approved design.
- `docs/superpowers/plans/2026-09-23-dotfiles.md`: this implementation plan.

- [ ] **Step 3: Implement `install`**

Create executable `install` with this behavior:

```bash
#!/usr/bin/env bash
set -Eeuo pipefail

ROOT="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
DRY_RUN=false
BACKUP_DIR=""

usage() {
    printf '%s\n' 'Usage: install [--dry-run]'
    printf '%s\n' '  --dry-run  Show package and file operations without changing the system'
    printf '%s\n' '  --help     Show this help'
}

log() { printf '%s\n' "$*"; }
warn() { printf 'warning: %s\n' "$*" >&2; }
die() { printf 'error: %s\n' "$*" >&2; exit 1; }

while (($#)); do
    case "$1" in
        --dry-run) DRY_RUN=true ;;
        -h|--help) usage; exit 0 ;;
        *) die "unknown option: $1" ;;
    esac
    shift
done

[[ -r /etc/os-release ]] || die 'cannot read /etc/os-release'
# shellcheck disable=SC1091
source /etc/os-release

case "${ID:-}" in
    fedora)
        manager=dnf
        packages=(
            git bash fastfetch niri waybar alacritty fuzzel cava btop matugen
            swaybg swaylock wlogout playerctl brightnessctl pavucontrol
            pipewire wireplumber neovim xpad orca cascadia-code-nf-fonts
            papirus-icon-theme
        )
        ;;
    arch)
        manager=pacman
        packages=(
            git bash fastfetch niri waybar alacritty fuzzel cava btop matugen
            swaybg swaylock wlogout playerctl brightnessctl pavucontrol
            pipewire wireplumber neovim xpad orca ttf-cascadia-code-nerd
            papirus-icon-theme
        )
        ;;
    *) die "unsupported distribution: ${ID:-unknown}" ;;
esac

command -v "$manager" >/dev/null 2>&1 || die "$manager is required"

install_packages() {
    if $DRY_RUN; then
        case "$manager" in
            dnf) printf 'would run: dnf install -y %s\n' "${packages[*]}" ;;
            pacman) printf 'would run: pacman -S --needed --noconfirm %s\n' "${packages[*]}" ;;
        esac
        return
    fi

    if ((EUID == 0)); then
        case "$manager" in
            dnf) dnf install -y "${packages[@]}" ;;
            pacman) pacman -S --needed --noconfirm "${packages[@]}" ;;
        esac
    elif command -v sudo >/dev/null 2>&1; then
        case "$manager" in
            dnf) sudo dnf install -y "${packages[@]}" ;;
            pacman) sudo pacman -S --needed --noconfirm "${packages[@]}" ;;
        esac
    else
        die 'sudo is required to install packages'
    fi
}

run() {
    if $DRY_RUN; then
        printf '+'
        printf ' %q' "$@"
        printf '\n'
    else
        "$@"
    fi
}

backup_file() {
    local destination="$1"
    if [[ -z "$BACKUP_DIR" ]]; then
        local backup_root="$HOME/.local/state/dotfiles/backups"
        mkdir -p "$backup_root"
        BACKUP_DIR="$(mktemp -d "$backup_root/$(date -u +%Y%m%dT%H%M%SZ)-XXXXXX")"
    fi

    local relative="${destination#"$HOME"/}"
    mkdir -p "$BACKUP_DIR/$(dirname "$relative")"
    cp -a "$destination" "$BACKUP_DIR/$relative"
}

copy_file() {
    local source="$1"
    local destination="$2"

    if [[ -e "$destination" || -L "$destination" ]]; then
        if cmp -s "$source" "$destination"; then
            return
        fi
        if ! $DRY_RUN; then
            backup_file "$destination"
        fi
    fi

    run install -D -m "$(stat -c '%a' "$source")" "$source" "$destination"
}

copy_home_tree() {
    [[ -d "$ROOT/home" ]] || die 'repository home directory is missing'
    while IFS= read -r -d '' source; do
        local relative="${source#"$ROOT/home/"}"
        case "$relative" in
            .config/niri/hardware.kdl|.config/current_wallpaper) continue ;;
        esac
        copy_file "$source" "$HOME/$relative"
    done < <(find "$ROOT/home" -type f -print0)
}

copy_bin_tree() {
    local source
    for source in "$ROOT/bin"/*; do
        [[ -f "$source" ]] || continue
        copy_file "$source" "$HOME/.local/bin/${source##*/}"
    done
}

install_packages
copy_home_tree
copy_bin_tree

if [[ ! -e "$HOME/.config/niri/hardware.kdl" ]]; then
    copy_file "$ROOT/home/.config/niri/hardware.example.kdl" "$HOME/.config/niri/hardware.kdl"
fi

if ! command -v firefox >/dev/null 2>&1; then
    warn 'Firefox is not installed; install it separately when wanted'
fi

log 'Installation complete.'
log 'Set Git identity locally, edit ~/.config/niri/hardware.kdl, and choose a wallpaper with set-theme.'
```
